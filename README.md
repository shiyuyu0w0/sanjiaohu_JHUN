# 三角狐

三角狐是一款面向江汉大学学生的 Android 校园工具，将课表、成绩、考试和常用校园服务集中在一个应用中。支持 Android 8.0 及以上系统。

## 功能

### 课表

- 登录教务系统后同步个人课表，并按学期保存在本机。
- 以完整周视图展示周一至周日、每天十二节课程，点击课程可查看详细信息。
- 支持左右滑动切换教学周、快速回到本周和手动校准教学周。
- 支持添加、编辑和删除自定义课程，自定义内容不会被教务课表更新覆盖。
- 新课表与本地记录不同时提供核对界面，也可恢复上一份课表。
- 已同步的课表支持离线查看。

### 成绩与考试

- 按学期查询课程成绩，展示课程名称、学分、成绩和绩点等信息。
- 提供平均成绩、平均学分绩点、加权平均成绩、已修学分和课程环节汇总。
- 查询考试时间、地点、座位和备注，并显示考试倒计时及进行状态。
- 成绩和考试记录按学期缓存，网络不可用时仍可查看上次成功获取的数据。

### 校园服务

- 查询宿舍空调与照明剩余电量，支持分别发起缴费并跳转支付宝。
- 进入学校网上报修服务，教务账号与统一认证账号分开管理。
- 查看校园地图、搜索校园地点并定位当前位置。
- 查看内置校历，支持缩放、拖动和横竖屏浏览。
- 在校园网内访问大物实验报告系统，并通过系统文件选择器提交报告文件。

### 个性化

- 支持跟随系统深色模式。
- 可选择主题色，也可从课表壁纸自动提取配色。
- 支持课表壁纸裁切、缩放和定位，并可调整课程卡片透明度。
- 界面会根据不同屏幕尺寸和方向自适应排版。

### 账号与数据

- 支持教务系统和统一身份认证自动登录。
- 登录凭证使用 Android Keystore 和 AES-GCM 加密后保存在本机。
- 课表、成绩、考试和自定义课程均存放在应用私有目录。
- 数据更新完整通过校验后才替换本地记录，连接或解析失败时保留已有内容。
- 可分别退出账号、关闭自动登录或清除已保存的登录凭证。

### 应用更新

- 在「个人 → 关于 → 检查更新」查看版本和更新内容，支持加速及 GitHub 官方下载线路。
- 下载后校验安装包，再由用户通过 Android 系统确认覆盖安装。
- 发布步骤、版本清单和校验脚本见 [应用内更新与发布](docs/in-app-updates.md)。

## 优点

- **常用信息集中**：课表、成绩、考试和校园服务无需在多个入口之间反复切换。
- **离线可用**：先展示本地数据，再尝试联网更新，教务系统临时不可用也不影响日常查看。
- **更新更稳妥**：课表变化可先核对再使用，并保留上一份记录供恢复。
- **本地优先**：个人数据和加密凭证保存在设备上，不依赖额外的第三方账号或云端服务。
- **操作顺手**：切周手势、考试倒计时、宿舍选择记忆和自动登录减少重复操作。
- **界面统一**：原生页面、深色模式、主题配色和壁纸定制保持一致的视觉体验。
- **兼容范围明确**：面向 Android 8.0 及以上系统，适配不同屏幕尺寸与横竖屏场景。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 平台 | Android SDK，最低 Android 8.0（API 26） |
| 开发语言 | Java 8、JavaScript |
| 构建 | Gradle、Android Gradle Plugin 8.13.0 |
| 界面 | Android 原生 View、自定义 View 与 Drawable |
| 校园系统接入 | WebView、JavaScript 页面适配、原生网络请求 |
| 本地存储 | JSON、SharedPreferences、AtomicFile、应用私有目录 |
| 凭证保护 | Android Keystore、AES-256-GCM |
| 日期时间 | `java.time` |

项目以 Android 平台原生能力为主，不依赖第三方 UI 框架。原生界面负责日常浏览和交互，WebView 与页面适配脚本用于连接学校现有系统，本地缓存与原子写入用于保证弱网和异常情况下的数据可用性。
