用户原始要求：明显升级界面质感，优化底部三页切换、独立页面跳转、底栏图标反馈、列表与卡片出现效果。允许引入 AndroidX / Material；Claude 核对本地发布脚本后采用原生实现，保持现有打包流程可用。

## 对照 Claude 的九项目标

| 目标 | 已落地的实现 |
| --- | --- |
| 设计标记与共享控件 | `Ui` 统一圆角、字号、间距、描边、投影、文字和动画辅助方法 |
| 卡片与浅色层次 | 面板与背景分色，浅色／深色主题均有独立面板、描边与浮层 |
| 首页、成绩密度与标题 | 首页按学业／校园／服务分组；成绩摘要直接显示已有统计，课程与分数左右排列；完成中断处的学期选择控件统一 |
| 底部三页切换 | 新旧内容衔接退场／入场，按标签顺序及页面层级决定方向，结束与中断时清理旧视图 |
| 独立页面动效 | 应用主题统一绑定打开／关闭的滑动、淡入淡出和轻微缩放 |
| 底栏反馈 | 涟漪、选中色过渡、图标回弹 |
| 列表和卡片入场 | 限制错峰延迟；修复将 MATCH_PARENT／WRAP_CONTENT 当作空白占位而跳过动画的问题 |
| 系统栏与字体 | 共用系统栏内边距；API 30+ 设置系统栏图标明暗，兼容旧版；统一 sans-serif |
| 编译、测试、差异检查 | 使用真实 Android SDK 完整构建、原有密钥签名、45 组本地测试、11 项更新发布脚本检查、Git 差异空白检查 |

## 接手后补齐及修复

- 完成学期选择器、按钮和课表中断处的样式整理；保留课表小单元格专用的小字号，不机械放大而导致课程被挤掉。
- 卡片入场正确处理 Android 布局尺寸标记，空白间隔及隐藏视图不占错峰序号；关闭动画时恢复完整可见状态。
- 成绩／考试两个同层页面互跳采用互逆方向；旧标题随旧内容退场，避免标题重叠。
- 动画结束回调持有对应的入场视图，避免依赖随后可能变化的页面字段。
- 首页网格允许卡片投影越过子视图边界，防止阴影被裁掉。
- 补齐本地测试用 JSON 数值／字符串接口，将 Cookie 测试替身回调签名与 Android SDK 对齐；这些测试替身不会进入安装包。
- 新增可重复执行的本地测试入口和入场动画尺寸回归用例。
