# 今日课表桌面小组件

在「课程 → 更多 → 桌面小组件」中添加，入口位于更多菜单最底部；也可长按桌面空白处，在小组件列表中找到「三角狐 → 今日课表」。默认占用 **4 × 2**，允许横向调整，禁止纵向拉伸。各桌面的格子大小不同，最终像素尺寸由桌面决定。

左侧显示日期和图片，点击左侧可选择、裁切、保存图片或恢复默认图片。每个小组件保存独立的本机图片副本，不修改课表背景，也不需要相册全量读取权限。取消裁切、返回配置页不保存时，原图片不变。右侧点击后进入课程页并回到当前周。

卡片与设置页自动跟随系统深浅色，保留图片原色，桌面图片下方不再显示操作文字。编辑页只保留预览、更换图片、恢复默认和右上角保存；管理页显示添加按钮和现有小组件缩略图。桌面颜色使用日间/夜间资源，缓存的 RemoteViews 也能在系统切换外观时重新解析，不依赖应用在前台。

读取当前选中学期的已保存课表和自定义课程，以北京时间计算当天和实际教学周，不使用用户正在浏览的周次。未校准、没有数据和超出学期分别提示，不推测课表。通常显示两门正在进行或尚未结束的课程，全天结束后显示最后两门；底部提示其他课程数量。紧凑尺寸或较大系统字体下减少为一门，避免文字重叠。

课表保存、恢复、学期切换和周次校准会刷新桌面。系统周期更新为 30 分钟，并在下一次上课、下课或午夜安排非精确、非唤醒的更新。重启和系统时间变化后重排更新；省电模式可能推迟后台更新，不申请精确闹钟权限。小组件不自动联网同步课表。

验证入口：

- `scripts/test-local.ps1` 包含 `WidgetScheduleTest`，覆盖周次、星期、学期范围、自定义课程、上下课和午夜边界。
- `scripts/build-ui-test.ps1` 包含 `WidgetInstrumentation`，检查系统注册的 4 × 2 和横向调整属性、真实 RemoteViews、图片隔离、12 种尺寸/字体组合和点击跳转。该测试临时创建自己的 widget host 并清理；在测试模拟器执行前用 `adb shell appwidget grantbind --package cn.jhun.sanjiaohu --user 0` 授权，执行后用 `revokebind` 撤回。
- 已在 API 35 桌面手动检查添加窗口显示 4 × 2、选择图片、裁切、保存和点击图片再次配置。
