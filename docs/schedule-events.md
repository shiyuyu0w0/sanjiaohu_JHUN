# 单次日程

在课程页点按空白格，可打开“添加日程”。标题必填，备注选填；开始和结束默认取点击格子的时间，可在 **08:20–21:40** 内按分钟选择，不必对齐节次。结束时间必须晚于开始时间。

时间选择使用与应用配色一致的底部弹层，两列上下滚动分别选择小时和分钟。小时仅显示 08–21，边界小时自动限制分钟；开始最晚 21:39，结束最早 08:21，保证至少留出一分钟。支持惯性滑动、自动对齐、轻触相邻数字和系统允许的轻震动；点击“确定”才写回时间，取消保留原时间和编辑内容。支持深色模式、键盘和无障碍调整。

- 保存后卡片按时间定位到原有格子；超过一节课时连续跨格显示，午休、晚餐仍保持原来的窄条高度，日程不会改变其他课程和空白格的大小。
- 新建或编辑保存前检查当天课程，包括教务与自定义课程。发生重叠时提示冲突课程名称，不保存，并保留标题、备注和时间草稿；时间端点刚好相接不算冲突。校准后按具体日期的教学周检查，未校准时按当前显示的全部课程检查。已有日程之间仍可并排显示。
- 设置背景图片后，各时段使用一致的半透明底色，长日程不会产生遮住图片的横条。
- 日程绑定点击时列头对应的具体日期和当前学期，不按教学周重复。切换周次、重新校准或重开应用不会修改保存的日期。
- 没有校准时，也按课表列头显示的日期创建日程。
- 点按日程可查看完整备注、编辑或删除。取消编辑不会保存改动。
- 日程独立保存于本机 `schedule-events.json`，教务同步和自定义课程不会覆盖它。
- 存储格式 v2 使用当天的分钟数；v1 的节次数据读取时转换为原课表对应时间，标题、备注、日期和标识保持不变。
- 旧版保存的超范围日程仍可读取，原数据不自动修改；编辑保存时需调整至支持的时间范围。已有数据后来因课程更新发生重叠时仍并排显示，编辑保存会检查冲突。

验证：`ScheduleEventTest` 覆盖日期筛选、时间边界、固定格子坐标、教学周与课程冲突；`ScheduleEventInstrumentation` 在 Android 上覆盖实际空格点击、时间选择器、默认一格、分钟选择、跨格显示、冲突拒绝且保留草稿、相接端点、范围拒绝、切周/学期、重开读取、格式迁移、编辑取消和删除。`TimeWheelInstrumentation` 覆盖滑动、边界联动、确认、取消和无障碍。

`EventWallpaperInstrumentation` 对实际组合后的课表逐像素检查背景连续性，覆盖长日程、单格、跨午休、深浅色、校准前后和不同宽高，并确认原有格子尺寸不变、日程卡片没有越出课表。
