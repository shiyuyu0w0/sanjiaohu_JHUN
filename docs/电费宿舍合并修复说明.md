## 一、问题原因

学校 `getRoom.do` 在 `南校区照明` 区下，把这两栋公寓各自拆成**两个独立楼栋**：

| id | name |
|---|---|
| `B`  | 留学生公寓B照明 |
| `BK` | 留学生公寓B空调 |
| `A`  | 研究生公寓A照明 |
| `AK` | 研究生公寓A空调 |

`buildings()` 用 `building.name` 做 key，于是下拉里出现 **4 个独立选项**。
用户选「留学生公寓B照明」后：

1. `floors()` 只查 `B` 这一个 branch
2. 该 branch 的 `kind()` 据楼名判为 `LIGHT`
3. 于是 `query()` 只能填上照明槽位，**空调卡片永远是空的**

**表现**：只出现一张卡 / 显示「学校未提供可明确对应的电表」。
**两类公寓症状完全相同** —— 这正是要一并修掉的一致性问题。

### 为什么不改下游

合并后能自动生效，是因为既有代码本来就是**多分支**结构：

- `floors()` 已是 `for(Branch b:branches)` 遍历所有 branch
  （`ElectricityApi.java:71`）
- `query()` 已按 `m.floor.kind` 把电表分派到 AC / LIGHT 两个槽位
  （`ElectricityPanel.java:73` 起，分派在 `:76`）

所以**只要让一个选项携带 2 个 Branch，其余全部自动工作**。
这是本次改动很小的根本原因 —— **不要把 `pair()` 挪到 Panel 层**，那会把简单问题搞复杂。

## 二、核心修改（Java）

### 1. `app/src/main/java/cn/jhun/sanjiaohu/ElectricityModel.java`

在 `static final int UNKNOWN=0, AC=1, LIGHT=2;` 之后插入：

```java
    // The school lists some dorms as two separate buildings ("X照明" and "X空调")
    // while the app shows one option with both cards. Pair them only by their
    // exact shared base name, and only when both halves are present.
    static final String AC_SUFFIX="空调", LIGHT_SUFFIX="照明";
    /** Base name of a building that names its meter kind, or null when it does not. */
    static String meterBase(String building){
        if(building==null)return null;
        String name=building.trim();
        String base=null;
        if(name.endsWith(AC_SUFFIX))base=name.substring(0,name.length()-AC_SUFFIX.length());
        else if(name.endsWith(LIGHT_SUFFIX))base=name.substring(0,name.length()-LIGHT_SUFFIX.length());
        // A bare "空调"/"照明" would leave an empty base; never pair on that.
        return base!=null&&!base.isEmpty()?base:null;
    }
    /** True when this building names the AC half of a pair. */
    static boolean isAcHalf(String building){
        return building!=null&&building.trim().endsWith(AC_SUFFIX)&&meterBase(building)!=null;
    }
    /** True when this building names the LIGHT half of a pair. */
    static boolean isLightHalf(String building){
        return building!=null&&building.trim().endsWith(LIGHT_SUFFIX)&&meterBase(building)!=null;
    }
```

> ⚠️ `AC_SUFFIX` / `LIGHT_SUFFIX` 必须是**包级可见**（`static final`）。
> 写成 `private` 会编译失败，因为 `ElectricityApi.pair()` 要引用它们。
> 保持单一事实来源，别在两个类里各写一份字面量。

### 2. `app/src/main/java/cn/jhun/sanjiaohu/ElectricityApi.java`

**改动 A** —— `buildings()` 的最后一行：

```java
// 改前
if(out.isEmpty())throw new IOException("学校未返回可选宿舍楼");return out;
// 改后
if(out.isEmpty())throw new IOException("学校未返回可选宿舍楼");return pair(out);
```

**改动 B** —— 在 `buildings()` 之后、`floors()` 之前插入：

```java
    // Some dorms are listed as two buildings ("X照明" + "X空调") but the page shows a
    // single option with both meters. Merge only a complete pair under the shared base
    // name; every unpaired building keeps its own name and single meter.
    static SortedMap<String,List<Branch>> pair(SortedMap<String,List<Branch>> source){
        SortedMap<String,List<Branch>> out=new TreeMap<>();
        for(Map.Entry<String,List<Branch>> entry:source.entrySet()){
            String name=entry.getKey(),base=ElectricityModel.meterBase(name);
            if(base!=null){
                String light=base+ElectricityModel.LIGHT_SUFFIX,ac=base+ElectricityModel.AC_SUFFIX;
                if(source.containsKey(light)&&source.containsKey(ac)){
                    List<Branch> merged=out.computeIfAbsent(base,k->new ArrayList<>());
                    for(Branch b:source.get(light))if(!merged.contains(b))merged.add(b);
                    for(Branch b:source.get(ac))if(!merged.contains(b))merged.add(b);
                    continue;
                }
            }
            List<Branch> existing=out.get(name);
            if(existing==null)out.put(name,new ArrayList<>(entry.getValue()));
            else for(Branch b:entry.getValue())if(!existing.contains(b))existing.add(b);
        }
        return out;
    }
```

`java.util.*` 已经 import，`Map.Entry` 无需额外导入。

### 设计要点（重构时别丢掉）

| # | 约束 | 原因 |
|---|---|---|
| 1 | **只合并成对的** | 必须 `X照明` 与 `X空调` 同时存在。单独一个 `留学生公寓B照明` 保持原样 |
| 2 | **绝不猜** | 裸 `空调`/`照明` 去后缀后基名为空 → `meterBase` 返回 `null` → 不配对 |
| 3 | **普通楼栋零影响** | `北区16舍`、`南区1舍`、`清源书店` 不含用途后缀，走原分支 |
| 4 | **幂等** | `pair(pair(x)) == pair(x)`，重复调用安全 |
| 5 | **照明在前、空调在后** | 合并顺序固定 light → ac，便于断言 |

这些约束对应 `ElectricityModel` 的类注释与项目既有立场：
*"Identifiers always come from the school's room directory, never from guessed ranges."*

## 六、打包 APK

### 三个环境坑（实测踩过）

**① `aapt2` 打不开含中文的绝对路径。**
若项目路径含中文（如 `副本`），`aapt2 compile --dir "绝对路径"` 会报
`failed to open directory: 系统找不到指定的文件。(2)`。
**改用相对路径**即可：

```powershell
& "$tool/aapt2.exe" compile --dir "app/src/main/res" -o "$W/resources.zip"
```

**② `javac` 传参被 PowerShell 吞掉** → 一律用 `@响应文件`，路径用**正斜杠**，
含空格的加引号。

**③ `apksigner` 的假失败。** JDK 21+ 下它往 stderr 打 `WARNING`，
PowerShell 会当成错误，`$LASTEXITCODE` 看似 `-1`，**但文件其实已生成**。
用 `2>$null` 屏蔽，或直接检查产物。

### 完整流程

```powershell
cd "<项目根目录>"
$Java='C:/Program Files/Android/Android Studio/jbr'
$sdk="$env:LOCALAPPDATA/Android/Sdk"
$aj="$sdk/platforms/android-36.1/android.jar"
$tool="$sdk/build-tools/36.1.0"
$W="build/android-build"
Remove-Item -Recurse -Force $W -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force -Path "$W/classes","$W/generated","$W/dex" | Out-Null

# 1) 资源（相对路径！）
& "$tool/aapt2.exe" compile --dir "app/src/main/res" -o "$W/resources.zip"
$mt=Get-Content -LiteralPath "app/src/main/AndroidManifest.xml" -Raw -Encoding UTF8
[IO.File]::WriteAllText("$PWD/$W/AndroidManifest.xml",
  $mt.Replace('<manifest ','<manifest package="cn.jhun.sanjiaohu" '),
  (New-Object Text.UTF8Encoding($false)))          # 必须无 BOM，aapt2 会拒绝 BOM
& "$tool/aapt2.exe" link -o "$W/unsigned.apk" -I $aj `
  --manifest "$W/AndroidManifest.xml" -A "app/src/main/assets" `
  --java "$W/generated" "$W/resources.zip"

# 2) Java（相对路径 + 响应文件）
$ajs=$aj -replace '\\','/'
$stub=("$sdk/build-tools/36.1.0/core-lambda-stubs.jar") -replace '\\','/'
$q='"'
$srcs=@()
$srcs+=Get-ChildItem "app/src/main/java" -Recurse -Filter '*.java' |
  ForEach-Object { $q+($_.FullName.Replace("$PWD\",'') -replace '\\','/')+$q }
$srcs+=Get-ChildItem "$W/generated" -Recurse -Filter '*.java' |
  ForEach-Object { $q+($_.FullName.Replace("$PWD\",'') -replace '\\','/')+$q }
[IO.File]::WriteAllLines("$W/javac-args.txt",
  @('-encoding','UTF-8','-source','8','-target','8','-Xlint:-options',
    '-bootclasspath',($q+$ajs+';'+$stub+$q),
    '-d',($q+($W -replace '\\','/')+'/classes'+$q)) + $srcs)
& "$Java/bin/javac.exe" "@$W/javac-args.txt"

# 3) dex + 对齐
& "$Java/bin/jar.exe" cf "$W/classes.jar" -C "$W/classes" .
& "$Java/bin/java.exe" -cp "$tool/lib/d8.jar" com.android.tools.r8.D8 `
  --lib $aj --min-api 26 --output "$W/dex" "$W/classes.jar"
& "$Java/bin/jar.exe" uf "$W/unsigned.apk" -C "$W/dex" classes.dex
& "$tool/zipalign.exe" -f -p 4 "$W/unsigned.apk" "$W/aligned.apk"

# 4) 签名
& "$Java/bin/java.exe" -jar "$tool/lib/apksigner.jar" sign `
  --ks "$PWD/signing/development.keystore" --ks-pass pass:android --key-pass pass:android `
  --out "Sanjiaohu-1.1.2.apk" "$W/aligned.apk"

# 5) 验证
& "$Java/bin/java.exe" -jar "$tool/lib/apksigner.jar" verify --verbose "Sanjiaohu-1.1.2.apk" 2>$null
& "$tool/aapt2.exe" dump badging "Sanjiaohu-1.1.2.apk" | Select-String '^package:'
Get-FileHash "Sanjiaohu-1.1.2.apk" -Algorithm SHA256
```

> 项目自带的 `build-local.ps1` 做了同样的事，正常路径下**优先用它**。
> 本节流程用于它在你的环境下失败时手动排查。
