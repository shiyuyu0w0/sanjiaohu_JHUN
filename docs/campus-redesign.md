# 三角狐界面重构

2026-10-26，按用户明确指定的 frontend-design 技能重新设计。原生 Android Java 实现，沿用现有签名、数据存储与校园服务流程。

## 当前设计

- 冷白背景、白色内容面板、湖蓝重点色；深色使用蓝灰层次。自定义主题色和壁纸取色继续可用。
- 首页从九块同质卡片改为今日课程、紧凑学业工具、校园与生活服务列表。未校准周次时要求校准，学期开始前不把日期错误归到第一周。
- 底部导航改为平面图标文字导航；减小圆角与浮层阴影，移除卡片逐个错峰入场。
- 成绩页保留学校统计与原始分值，取消分数大色块；考试状态集中在徽标，正文面板保持安静。
- 登录页、账号设置、图书检索、电费面板、关于页与公共弹层采用同一色彩、字号和控件体系。
- 保留页面进退、底栏点击、教学周手势与弹层动效。关闭系统动画时内容应正常显示。
- 学校托管的地图、报修、实验报告等网页继续使用学校原页面；应用外壳统一更新。没有改写第三方登录或支付界面。

## 闪退修复

旧 ui-review 包在 Android 15 上进入 LoginActivity 时出现 `PhoneWindow.getInsetsController` 空指针。多个子页面在 `setContentView` 前设置系统栏，导致窗口内部 DecorView 尚未创建。`AppTheme.applySystemBars` 先获取 DecorView，再读取控制器，并保留空值防护。新包包含该修复。
